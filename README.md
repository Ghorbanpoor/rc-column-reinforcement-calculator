# rc-column-reinforcement-calculator

A Streamlit-based graphical user interface (GUI) for preliminary longitudinal reinforcement estimation of reinforced concrete columns.

This project implements a proposed **Concrete–Steel Equivalent Area Balance Method** using tributary floor areas, slab thicknesses, column dimensions, story height, and an equivalent-area coefficient.

> **Disclaimer:** This is an experimental, conceptual calculation tool. It is not a validated structural design method and must not be used to determine final reinforcement for construction without independent engineering verification.

## Features

* **Interactive GUI:** A user-friendly interface built with Streamlit.
* **Multi-Story Input:** Specify the number of floors contributing to the column load.
* **Tributary Area:** Enter the tributary floor area associated with the column at each level.
* **Slab Thickness:** Define the thickness of each floor slab.
* **Column Geometry:** Specify column width, depth, and story height.
* **Amplification Factor:** Adjust the preliminary factor intended to represent additional loading effects.
* **Equivalent-Area Coefficient:** Configure the proposed coefficient used to represent the contribution of longitudinal reinforcement.
* **Automatic Calculations:** Estimate the required steel area and reinforcement ratio according to the proposed model.
* **Preliminary Rebar Suggestion:** Identify a nominal bar arrangement whose total steel area meets or exceeds the calculated estimate.
* **GitHub Codespaces Support:** Run the application in a cloud-based development environment without installing a local desktop GUI.

## Methodology

The application implements a proposed equivalent-volume balance concept.

The calculation uses the following inputs:

* Tributary area of each floor.
* Slab thickness at each floor.
* Number of contributing floors.
* Column cross-sectional dimensions.
* Story height of the column being investigated.
* Load amplification factor.
* Equivalent-area coefficient.

### Calculation Workflow

1. Calculate the representative tributary slab volume by multiplying each floor's tributary area by its slab thickness and summing the results.
2. Apply the selected amplification factor to the total representative volume.
3. Calculate the concrete volume of the column using its cross-sectional area and story height.
4. Estimate the equivalent longitudinal steel area using the proposed balance model and the selected coefficient.
5. Convert the calculated steel area into square centimeters.
6. Calculate the estimated reinforcement ratio.
7. Suggest a preliminary arrangement of longitudinal reinforcing bars.

### Proposed Model

The current implementation uses the following conceptual relationship:

**Amplified tributary volume = Column concrete volume + Equivalent steel volume**

The equivalent steel volume is represented using the selected coefficient multiplied by the longitudinal steel area and column height.

The coefficient is set to **100 by default** and can be changed through the GUI.

**Important:** The coefficient of 100 is a user-proposed modeling parameter. It is not established by the steel-to-concrete elastic modulus ratio, and the proposed relationship has not been validated as a structural design equation.

The calculated result should therefore be interpreted as an experimental estimate generated by the proposed model, not as a code-compliant reinforcement requirement.

## Installation and Usage

### Option 1: Run in GitHub Codespaces

1. Open the repository on GitHub.
2. Select **Code** and open the repository in a new Codespace.
3. Open the terminal.
4. Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

5. Start the application:

```bash
python -m streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

6. Open port `8501` when prompted by Codespaces to access the application in your browser.

### Option 2: Run Locally

Clone the repository:

```bash
git clone https://github.com/Ghorbanpoor/rc-column-reinforcement-calculator.git
```

Navigate to the project directory:

```bash
cd rc-column-reinforcement-calculator
```

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```

Streamlit will provide a local browser URL, typically `http://localhost:8501`.

Replace `YOUR-USERNAME` with your GitHub username.

## Input Parameters

| Parameter                   | Description                                          | Unit          |
| --------------------------- | ---------------------------------------------------- | ------------- |
| Number of stories           | Number of floors contributing to the selected column | Floors        |
| Tributary area              | Floor area associated with the column at each level  | m²            |
| Slab thickness              | Thickness of each contributing slab                  | cm            |
| Column width                | Width of the column cross-section                    | cm            |
| Column depth                | Depth of the column cross-section                    | cm            |
| Story height                | Height of the column being evaluated                 | m             |
| Amplification factor        | User-selected multiplier for the conceptual model    | Dimensionless |
| Equivalent-area coefficient | Proposed coefficient for the steel contribution      | Dimensionless |

## Output Parameters

The application reports:

* Total representative tributary slab volume.
* Amplified representative volume.
* Concrete column volume.
* Estimated longitudinal reinforcement area in cm².
* Estimated reinforcement ratio.
* A preliminary reinforcing-bar arrangement based on the estimated area.

The suggested bar arrangement considers nominal bar area only. It does not verify bar placement, clear spacing, cover, confinement, development length, lap splices, or the actual structural demand.

## Engineering Limitations

The proposed method is intended for conceptual exploration and preliminary research. It does not calculate the actual axial load or the design capacity of a reinforced concrete column.

In particular, the current implementation does not explicitly account for:

* Actual dead loads from slabs, beams, walls, finishes, and other structural components.
* Live loads and applicable load combinations.
* Seismic base acceleration, mass distribution, modal response, or lateral force distribution.
* Wind loads.
* Axial force and bending moment interaction.
* Column slenderness and second-order effects.
* Concrete strength and reinforcing steel yield strength.
* Minimum and maximum reinforcement requirements.
* Seismic detailing and confinement requirements.
* Foundation flexibility, frame action, and load redistribution.
* Applicable national or international structural design codes.

The amplification factor is a user-defined parameter and does not replace code-based gravity or seismic load combinations.

**Do not use the calculated reinforcement area as an approved construction design.** Final column design must be performed and verified by a qualified structural engineer using appropriate structural analysis, material properties, and applicable building codes.

## Research and Development

Potential future improvements include:

* Validation against conventional reinforced concrete column design calculations.
* Comparison with ETABS or other structural analysis software.
* Incorporation of concrete compressive strength and steel yield strength.
* Explicit calculation of tributary gravity loads and column axial forces.
* Integration of bending moments and axial–moment interaction checks.
* Code-based reinforcement limits and seismic detailing checks.
* Sensitivity analysis to investigate the influence of the equivalent-area coefficient.
* Automated generation of calculation reports.

These improvements would help establish whether the proposed concept can be developed into a useful preliminary-design or educational tool.
